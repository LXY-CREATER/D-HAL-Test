# 双车协同平衡车系统

基于 WHEELTEC B570 平衡小车的双车协同搬运系统，实现两车一字排开协同运输功能。

## 通信协议 (v3.0)

### 主机 → 从机

每50ms发送一次，6字节结构化数据包：

| 字节 | 内容 | 说明 |
|------|------|------|
| 0 | 0xAA | 主机标志 |
| 1 | cmd | 协同命令 |
| 2 | speed | 目标速度 (i8, -128~127) |
| 3 | yaw_H | 主机航向高字节 |
| 4 | yaw_L | 主机航向低字节 |
| 5 | turn_radius | 转弯半径 |

### 协同命令定义

| 命令 | 值 | 说明 |
|------|-----|------|
| COOP_CMD_FORWARD | 0x01 | 前进 |
| COOP_CMD_BACKWARD | 0x02 | 后退 |
| COOP_CMD_STOP | 0x03 | 停止 |
| COOP_CMD_TURN_LEFT | 0x04 | 左转 |
| COOP_CMD_TURN_RIGHT | 0x05 | 右转 |

## 手机APP控制指令

主机通过蓝牙串口接收手机APP指令：

| 按键 | 指令 | 功能 |
|------|------|------|
| A | 0x41 | 前进 |
| E | 0x45 | 后退 |
| B/C | 0x42/0x43 | 右转 |
| G/H | 0x47/0x48 | 左转 |
| + | 0x2B | 加速（直行速度+5） |
| - | 0x2D | 减速（直行速度-5） |
| Z | 0x5A | 停止 |

## 协同控制逻辑

### 1. 速度协同

```
主机速度设置：
- 默认直行速度：20
- 默认转弯速度：10（直行速度的1/2）
- 速度范围：12 ~ 50

从机速度计算：
- Target_Velocity = Master_Target_Speed × 0.8（80%）
- 最小速度兜底：8（防止电机驱动力不足）
- 速度渐变：Current_Velocity += (Target - Current) × 0.15
```

### 2. 转向协同

```
主从机转向系数一致：
- 转向系数：0.65
- 转向限幅系数：0.80（防止车轮速度为负）

转弯时：
- 主从机同时收到转向指令
- 转向幅度相同，确保转弯同步
- 转弯半径由转向系数决定
```

### 3. 航向修正

```
仅在前进/后退时激活：
- yaw_error = Master_Target_Yaw - Yaw
- adj = yaw_error × 0.15
- Turn_Target += adj（小幅度航向修正）

转弯时禁用航向修正，避免冲突
```

### 4. 速度渐变机制

从机实现平滑加速，消除速度突变导致的顿挫：

```c
Current_Velocity += (Target_Velocity_Raw - Current_Velocity) * 0.15f;
Target_Velocity = Current_Velocity;
```

每周期向目标速度逼近15%，实现平滑过渡。

## 编译说明

### 编译环境

- Keil MDK v5
- ARMCLANG Compiler v6.23
- STM32Cube HAL Library

### 编译步骤

1. 打开主机项目：`B570(主)/B570(主)/7.WHEELTEC B570 平衡小车源码（HAL库版)/B570/MDK-ARM/B570.uvprojx`
2. 点击 Build 按钮编译
3. 打开从机项目：`B570(从)/B570(从)/7.WHEELTEC B570 平衡小车源码（HAL库版)/B570/MDK-ARM/B570.uvprojx`
4. 点击 Build 按钮编译
5. 将生成的 .hex 文件烧录到对应硬件

## 使用说明

### 硬件连接

1. 主机：手机蓝牙连接主机蓝牙模块
2. 从机：主机USART3连接从机USART3（串口通信）

### 操作流程

1. 上电后两小车进入平衡状态
2. 切换到协同模式
3. 通过手机APP发送控制指令：
   - 点击 A/E 键控制前进/后退
   - 点击 B/C/G/H 键控制转弯
   - 点击 +/- 键调节速度
4. 从机会自动跟随主机运动

## 注意事项

1. 确保两小车蓝牙连接正常
2. 协同模式下速度建议设置在15-25之间
3. 转弯时速度会自动降低为直行速度的1/2
4. 如果从机卡顿，检查串口连接是否稳定
5. 速度渐变系数0.15可根据需求调整（0.20更快，0.10更慢）
