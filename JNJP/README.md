> 🏆 节能减排创新创业大赛参赛作品

---

## 一、项目概述

本项目针对山区道路弯道盲区导致的交通事故多发问题，提出了一套**零碳排放、无源无线、无需市电**的弯道会车安全预警解决方案。

### 核心理念

**车辆既是被检测对象，也是能量来源！**

- 车辆碾压压电陶瓷片产生电能
- 同一陶瓷片同时完成车辆检测和能量采集
- 真正做到取之于车，用之于路

### 预测性维护四大预警模型

| 预警等级 | 触发条件 | 故障预判 |
|---------|---------|---------|
| 【紧急】 | 10分钟无检测信号 | 陶瓷片可能脱落/线路断开 |
| 【严重】 | 基线异常偏低(<30) | 电荷放大器可能故障 |
| 【警告】 | 基线异常偏高(>150) | 传感器可能短路 |
| 【注意】 | 信号噪声过大(>50) | 接线可能松动 |
