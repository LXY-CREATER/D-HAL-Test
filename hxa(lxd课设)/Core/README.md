# 康复训练机器人控制系统

## 项目概述

这是一个基于STM32F103C8T6的康复训练机器人控制系统，实现了电机控制、编码器读取、蓝牙通信、OLED显示、语音识别和复健模式等功能。

## 硬件平台

- **微控制器**：STM32F103C8T6（ARM Cortex-M3内核）
- **电机驱动**：L298N或类似的H桥驱动模块
- **编码器**：增量式旋转编码器（AB相）
- **蓝牙模块**：HC-05或HC-06
- **OLED显示屏**：128x64 I2C接口
- **语音模块**：LD3320或类似的语音识别模块

## 功能特性

### 1. 电机控制（motor_controller.c）
- 正转、反转、停止、刹车功能
- PWM调速（0-100%占空比）
- 方向控制（PB5引脚）
- 位置限制和安全保护

### 2. 编码器读取（encoder_reader.c）
- 读取电机的位置（毫米）
- 读取电机的速度（毫米/秒）
- 位置校准和归零

### 3. 蓝牙通信（bluetooth_handler.c）
- 接收蓝牙命令
- 发送状态信息
- 命令队列管理

### 4. OLED显示（oled_display.c）
- 显示当前位置、速度、阻力级别
- 显示复健模式状态
- 显示电池电量（如果有）

### 5. 语音识别（voice_handler.c）
- 识别语音命令
- 控制电机运动
- 提供语音反馈

### 6. 复健模式（rehabilitation_mode.c）
- 阻抗控制算法
- 阻力级别调整（1-10级）
- 自动调整阻力
- 运动范围限制

## 蓝牙命令说明

| 命令 | 功能 |
|------|------|
| 0 | 停止电机 |
| 1 | 正转50%速度 |
| 2 | 反转50%速度 |
| 3 | 刹车 |
| 4 | 正转30%速度 |
| 5 | 反转30%速度 |
| 6 | 正转70%速度 |
| 7 | 反转70%速度 |
| M | 移动到中心位置 |
| Z | 设置零点 |
| R | 启动复健模式 |
| U | 增加阻力级别 |
| D | 减少阻力级别 |

## 复健模式说明

### 阻抗控制算法
复健模式使用阻抗控制算法，根据用户的运动产生相应的阻力：

```
力 = kp * 位移误差 + kd * 速度
```

- **kp（刚度系数）**：位置偏离目标位置越大，阻力越大
- **kd（阻尼系数）**：运动速度越快，阻力越大

### 阻力级别调整
- 级别1：阻力较小，适合康复初期
- 级别5：中等阻力，适合康复中期
- 级别10：最大阻力，适合康复后期

## 编译和烧录

### 编译环境
- Keil MDK 5.05或更高版本
- ARM GCC编译器

### 编译步骤
1. 打开Keil MDK项目文件
2. 选择目标设备为STM32F103C8T6
3. 点击编译按钮（Build）
4. 生成.axf或.hex文件

### 烧录步骤
1. 使用ST-Link或J-Link调试器
2. 连接调试器和开发板
3. 打开烧录软件（如ST-Link Utility）
4. 选择生成的.hex文件
5. 点击烧录按钮

## 使用说明

### 1. 硬件连接
- 电机驱动模块连接到STM32的PB4（PWM）和PB5（方向）引脚
- 编码器连接到STM32的定时器输入捕获引脚
- 蓝牙模块连接到STM32的USART引脚
- OLED显示屏连接到STM32的I2C引脚
- 语音模块连接到STM32的USART或SPI引脚

### 2. 上电初始化
- 开发板上电后，系统会进行初始化
- 电机控制器初始化
- 编码器读取器初始化
- 蓝牙模块初始化
- OLED显示屏初始化
- 语音模块初始化

### 3. 控制电机
- 通过蓝牙发送命令控制电机
- 通过语音命令控制电机
- 在复健模式下，手动推动电机进行康复训练

### 4. 调整阻力级别
- 在复健模式下，通过蓝牙发送"U"命令增加阻力级别
- 通过蓝牙发送"D"命令减少阻力级别
- 阻力级别会显示在OLED显示屏上

## 注意事项

1. **安全保护**：系统有位置限制和安全保护功能，当电机运动到极限位置时会自动停止
2. **阻力级别**：在复健模式下，阻力级别应根据用户的康复情况进行调整
3. **电源供应**：确保电源供应稳定，避免电机驱动模块过热
4. **硬件连接**：确保硬件连接正确，避免短路或接反极性

## 故障排除

### 1. 电机不转动
- 检查电源供应是否正常
- 检查电机驱动模块是否正常
- 检查STM32的引脚配置是否正确
- 检查代码中的电机控制逻辑是否正确

### 2. 编码器读数不准确
- 检查编码器的连接是否正确
- 检查编码器的分辨率设置是否正确
- 检查代码中的编码器读取逻辑是否正确

### 3. 蓝牙通信不稳定
- 检查蓝牙模块的连接是否正确
- 检查蓝牙模块的波特率设置是否正确
- 检查代码中的蓝牙通信逻辑是否正确

### 4. OLED显示屏不显示
- 检查OLED显示屏的连接是否正确
- 检查I2C总线是否正常
- 检查代码中的OLED显示逻辑是否正确
